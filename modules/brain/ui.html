Версии записи

Карточка записи

События появляются после сохранения данных. Заголовки ведут к актуальным записям; удалённые источники и их зависимые события пропадают.

Локальная консолидация

Поиск похожих формулировок, возможных противоречий и давно не использовавшихся записей. Объединение и архивирование выполняются по вашей кнопке.

Похожесть определяется по словам. Объединение сохраняет обе записи и источники, а в подбор для ответа входит один представитель группы. Изменение записи снимает её объединение. Новых запросов к Cloud.ru нет.

Цель → решения → сделано → осталось → место остановки

Проекты и прогресс выделяются автоматически из ваших сообщений. «Сделано» означает сообщение пользователя о завершении, а не проверку работы кода.

Ваши актуальные предпочтения

Собираются из явно высказанных пожеланий. Повторы объединяются, проектные правила остаются внутри проекта. Сведения можно подтвердить или исправить в памяти.

Контроль поиска и источников

Выполняется автоматически после разбора и изменений памяти.

Проверяется, находит ли поиск ожидаемую запись по контрольному вопросу и есть ли исходная цитата или ручное подтверждение. Вопросы составляет анализатор. Это проверка механизма памяти, а не оценка интеллекта или истинности фактов. Запросов к Cloud.ru при этой проверке нет.

Подключение Cloud.ru

Используйте Key Secret для сервиса Foundation Models.

На один ответ — один запрос. При включённой автопамяти затем выполняется ещё один запрос анализа. Массовых проверок моделей нет. Сохранение настроек само по себе не запускает тест генерации.

КАК РАСТЁТ ПАМЯТЬ

Разговор → разбор → воспоминание

Сохраняется цитата, её источник, вид и дата. Повторы объединяются, возможные противоречия помечаются для проверки.

Удалённая запись не появляется снова от повторного анализа той же цитаты. При удалении разговора его неподтверждённые воспоминания без других источников удаляются вместе с ним.

Это рост хранилища знаний и поиска. Веса облачной модели не изменяются.
